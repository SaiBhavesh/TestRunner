SolariAgent · computer operator

Input: website URL, test objective, campaign ID.

Output: browser session ID, screenshot reference, accessibility/console findings, task feasibility.

Tools: Solari browser/desktop MCP (requires configuration).

Safety: public pages only until explicit permission; no purchasing, account changes, or credential handling without authorization.

TeracAgent · human workforce manager

Input: study brief, participant target, reward budget.

Output: study ID, response IDs, real participant feedback.

Tools: Terac MCP/API (requires configuration).

Safety: honest compensation and study consent; never substitute agent-generated responses.

FinanceAgent · sponsor payment

Input: campaign order.

Output: verified Whop payment event and ledger entry.

Tools: Whop checkout + verified webhook (requires configuration).

Safety: never trust a browser-side paid flag.

CampaignAgent · orchestration

State machine: created → inspected → paid → recruiting → awaiting responses → analyzed → delivered.

Failure: stop on provider errors, preserve evidence, request intervention.

Audit: timestamped event log, source IDs, no fabricated success claims.
